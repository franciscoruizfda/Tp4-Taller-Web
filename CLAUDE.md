# BeatMind

## Idioma (obligatorio)

**Respondé siempre en español rioplatense**, en todos los mensajes: avisos de progreso, explicaciones y resúmenes finales. Nunca le escribas al usuario en inglés. El código y sus comentarios pueden seguir en inglés; lo que el usuario lee en el chat, no.

Tono cercano y claro, sin exceso de detalle técnico.

## Antes de trabajar

Leé `CONTEXT.md`: resume el proyecto, las decisiones tomadas y lo que no hay que romper (introducción siempre visible, consentimiento de Byte, identidad a decisión del usuario).

## Cómo abrir la app

- `npm.cmd run start` (o `Ctrl+Shift+B`): Vite con recarga automática.
- Live Server sobre `index.html`: redirige a `dist/`; solo refleja cambios después de `npm.cmd run build`.

En este entorno usar `npm.cmd` / `npx.cmd`, no `npm` / `npx`.

## Estética

Para cualquier cambio visual, usar la skill `beatmind-neon` (`.claude/skills/beatmind-neon/`).
